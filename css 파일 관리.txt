✅ style.css 담당 기능
이제 이 파일은 앱 전체에서 공통으로 사용하는 디자인만 담당해.

나중에 로그인 화면, 농사 기록, 작물 관리 페이지를 추가하더라도 이 스타일을 재사용할 수 있어.


✅ map.css 담당 기능
이 파일에서는 앞으로 네이버 지도와 관련된 디자인을 관리할 거야.

예를 들어 나중에 추가할 기능은 다음과 같아.

농지 경계 표시 ON/OFF 버튼

지도 확대 및 축소 버튼

현재 위치 이동 버튼

농지 검색창

지도 종류 변경 버튼

농지 선택 시 표시되는 정보창

지금은 기존 지도 디자인만 옮겨 놓은 상태야.



✅ farm-info.css 담당 기능
이 파일은 지도에서 농지를 클릭했을 때 나타나는 정보 영역을 담당해.

현재 표시하는 데이터는 다음과 같지.

정보	예시
농지 주소	경상북도 영양군 석보면 홍계리 351-1
농지 종류	밭
농지 면적	3,838.33㎡
농지 고유번호	13931941
PNU	4776035044103510001
앞으로 농지 정보 탭과 농지 등록 탭도 이 파일에서 디자인을 관리할 거야.
